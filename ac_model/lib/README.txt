Place the official CoolProp 8.0.0 Windows x64 shared library here as CoolProp.dll.
Download folder:
https://sourceforge.net/projects/coolprop/files/CoolProp/8.0.0/shared_library/Windows/64bit/
Use the file CoolProp.dll in that folder, not the 32bit or arm64 library.
The library must export propssi_. No Python, PIMS or compiler is needed.
The DLL is not included in this source package.
